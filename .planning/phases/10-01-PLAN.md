# Phase 10 — Production hardening

**Milestone:** v1.0.0 (first release tag)
**Depends on:** Phase 9
**Driver:** user directive — production quality, ready for actual users.

## Requirements

- **REQ-27 Responsive.** Landing, gallery, all six tabs, /new, /projects usable at
  375px. Tab bar scrolls horizontally; wiring/mech get touch-friendly fallbacks;
  tables scroll inside their own containers, never the page body.
- **REQ-28 Metadata.** Per-route titles/descriptions, OpenGraph/Twitter tags,
  proper favicon set, a designed 404, robots.txt. Project pages get dynamic titles.
- **REQ-29 Resilience.** Error boundary per tab so one bad package cannot
  white-screen the app; engine/API failure states with retry; localStorage
  quota/unavailable surfaced gently; malformed shared-link payloads rejected with
  a human message; WebGL-unavailable path verified.
- **REQ-30 Accessibility.** Full keyboard path through tabs and dialogs; visible
  focus everywhere; aria-labels on glyph-only buttons; AA contrast on dim text.
- **REQ-31 Ship as a release.** README deploy section (Vercel + plain node),
  version 1.0.0, tagged release with notes; final walkthrough on the production
  build recorded as a ship note.

## Success criteria

1. 375px walkthrough clean; keyboard-only walkthrough clean.
2. Lighthouse-style sanity: no console errors, reasonable CLS on tab switches.
3. Killing WebGL, corrupting a share link, and filling localStorage each degrade
   with a message, never a blank screen.
4. v1.0.0 tag pushed with release notes; issues closed.
