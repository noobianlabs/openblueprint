# Plan 01-01: Foundation — scaffold, schema, seeds, landing

**Phase**: 1 | **Requirements**: REQ-01, REQ-02, REQ-03 | **Executor**: orchestrator (spine work, quality-critical)

## Tasks

1. Manual Next.js scaffold (create-next-app conflicts with existing .claude/.planning):
   `package.json` (next@15, react@19, typescript, tailwindcss@4 via @tailwindcss/postcss, @xyflow/react), `tsconfig.json`, `next.config.ts`, `postcss.config.mjs`, `src/app/{layout,page,globals.css}`.
2. `src/lib/design/schema.ts` — `DesignPackage` and friends. The spine. Includes:
   - `PartCategory` = mcu | sensor | actuator | power | comms | display | enclosure | print3d | misc
   - `Part` { id, name, role, description, category, domain: electrical|mechanical, qty, unitCost, pins?, printSettings? }
   - `Connection` { id, from {partId,pin}, to {partId,pin}, net: data|power|ground, label? }
   - `AssemblyNode` { partId, children[] }
   - `InstructionPhase` { id, title, steps: Step[] }, `Step` { id, title, detail, tools[], parts[] }
   - `DesignPackage` { meta, tags, summary, parts, connections, assembly, tools, assumptions, phases }
   - `ProjectRecord` { slug, source: seed|user, starred?, createdAt, package }
3. `src/lib/design/seeds/` — 4 original seed projects (line-follower robot, balcony weather station, 4-key macropad, self-watering planter), each ≥10 parts, ≥6 connections, ≥3 instruction phases, realistic ~costs.
4. Design system in `globals.css` + layout: all-mono (JetBrains Mono via next/font), near-black background, category color tokens, light-on-dark tables, chip/badge styles.
5. Landing page `/`: nav (logo, ABOUT, GitHub, no fake sign-in), hero ("OPENBLUEPRINT SOMETHING REAL" is out — use original copy: "BLUEPRINT SOMETHING BUILDABLE"), prompt box (textarea + engine pill + submit), community grid from seeds (card: cover, name, part count, stars, author), footer.
6. `/p/[slug]` shell: loads seed by slug, header with title/author/tab bar (tabs stubbed), renders raw summary. Tab components arrive in Phases 2–3.
7. Verify: `npm run build` passes; dev server renders landing + project shell in browser.

## Must-haves (verify-phase checks)

- Landing renders with 4 seed cards; card click → `/p/[slug]` shows project name
- `tsc --noEmit` clean; `npm run build` clean
- No blueprint.io copy, assets, or fonts
