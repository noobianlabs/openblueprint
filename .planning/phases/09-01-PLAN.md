# Phase 9 — Workflow parity

**Milestone:** v1.3
**Depends on:** Phase 8 (visual parity)
**Driver:** user directive — complete the app as close to the original blueprint.io
workflow as possible before taking our own direction.

The original's project workflow that we still lack: a chat attached to each project
(follow-ups and design edits), version history with restore, rename, publish/share,
an idea generator on the prompt box, and an FAQ. Accounts, billing, credits, and
image/sketch upload are explicitly OUT — the first three don't belong in a keyless
open-source app, and vision input needs an API key (parked with the Claude engine).

## Requirements

- **REQ-21 Project chat.** Each project carries a chat (persisted per project in
  localStorage). Two message kinds: a QUESTION gets an answer derived from the
  design package (deterministic, template-based, truthful — e.g. power budget,
  why a part was chosen, what a pin does); an EDIT REQUEST changes the design.
  The local engine supports a bounded, honest set of edit intents parsed from the
  message (add/remove a capability from the archetype's option set, change the
  power choice, change the controls choice, regenerate mechanics); anything it
  cannot do it says so plainly instead of pretending. "Clear chat" per the original.
- **REQ-22 Version history.** Every generation and applied edit snapshots the
  package. A history panel lists versions with timestamps and the prompt/edit that
  produced each; restore replaces the current package (and itself snapshots).
- **REQ-23 Rename.** Pencil beside the project title, inline edit, persisted.
- **REQ-24 Share.** "Share" produces a link with the design compressed into the
  URL fragment (native CompressionStream → base64url; no dependency). A shared
  link renders read-only on `/p/shared` with a "Copy to my projects" action.
  Labelled honestly: anyone with the link can view; nothing is uploaded anywhere.
  Local "published" flag mirrors the original's publish/unpublish toggle.
- **REQ-25 Idea generator.** The prompt box's IDEA button cycles a curated,
  deterministic rotation of buildable prompt ideas; clicking fills the box.
- **REQ-26 FAQ page.** Real answers about THIS app: the two engines, keys, where
  data lives, what the 3D model is and is not, sharing, exports, non-affiliation.

## Success criteria

1. Ask "what powers the display?" on the weather station → truthful derived answer.
2. "Swap to battery power" on a lamp → edited design, new version in history,
   restore brings the old one back.
3. Rename survives reload; share link opens the design in a fresh private window
   with no localStorage; FAQ reachable from nav and footer.
4. `npm run build` clean; all existing behavior intact.
